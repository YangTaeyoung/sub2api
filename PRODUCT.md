## Platform

web

## Users

Korean-speaking operators administering a self-hosted Sub2API installation.

## Product Purpose

Manage connected AI provider accounts, API keys, routing groups, and usage through one self-hosted gateway.

## Operating Context

The renewal starts from release 0.2.19 image source revision dece26153621959ccd7635814f4b2d08304e681a. Docker Compose uses PostgreSQL and Redis. Existing installations can enable personal simple mode. Host-specific paths and administrator credentials stay outside source control.

## Capabilities and Constraints

Preserve production data, provider credentials, API keys, settings, volumes, deployment secrets, and domain. The fork changes frontend UI, Korean localization, and light/dark theme quality. Do not publish production secrets or data to the fork. Preserve existing functions. Korean must be a native locale, not a browser-translation overlay.

## Brand Commitments

Keep the name Sub2API. Replace the previous appearance with the selected Workspace direction: a compact, quiet operations interface benchmarked against Linear. Give typography, tables, charts, and both themes the same attention.

## Evidence on Hand

The selected concept and subsequent adversarial review use real operational screens. Private screenshots and operational metrics stay outside source control. Never fabricate trends, uptime, error rates, or model availability. The selected-period summary and model rows must use the same data snapshot.

## Product Principles

- Understand account readiness and usage quickly.
- Use natural Korean labels and clear units.
- Preserve familiar admin interactions.
- Make light and dark themes equally readable.
- Follow the selected Workspace direction and the documented commercial-reference review contract.
